# hocMay

hocMay helps learners write better chatbot prompts through practice and feedback. A separate collection of illustrated guides teaches learners how to use NotebookLM.

The first release covers one complete practice cycle. A learner submits a prompt for an authored scenario, reads feedback for each rubric criterion, revises the prompt, and unlocks the next lesson when the passing conditions are met. One illustrated NotebookLM tutorial accompanies the practice path.
